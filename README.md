# Fit

Prosta aplikacja treningowa (PWA): treningi siłowe A i B, Pobudka, plan biegowy na 5 km.
Działa pod adresem https://fit.hipnopol.pl (GitHub Pages).

- Plan ćwiczeń: stała `PLAN` w `index.html`, biegi: stała `RUNS`.
- Po każdej zmianie plików podbij `VERSION` w `sw.js`, żeby telefony pobrały nową wersję.
- Treningi zapisują się tylko w telefonie; kopię robisz przyciskiem „Zapisz kopię”.
